---
title: Toast options
description: Everything a single toast can be configured with.
---

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | generated | Reusing an id replaces that toast's content in place. |
| `title` | `string` | name of the type | Shown in the pill. The defaults are in `DEFAULT_TITLES`: Notification, Success, Info, Warning, Error and Loading. |
| `description` | `Content` | — | Shown when the toast opens. |
| `type` | `"neutral" \| "success" \| "info" \| "warning" \| "error" \| "loading"` | set by the method | Icon and tone. |
| `icon` | `Content \| null` | built-in icon of the type | A string starting with `<svg` is rendered as inline SVG. `null` hides the icon. |
| `position` | `Position` | the toaster's | One of `top-left`, `top-center`, `top-right`, `bottom-left`, `bottom-center`, `bottom-right`. |
| `duration` | `number \| null` | `5000`, `null` for loading toasts | Milliseconds until it is dismissed. `null` or `Infinity` keeps it. |
| `action` | `{ label, onClick, dismiss? }` | — | A button shown with the title. `onClick(event, toast)` gets `{ id, dismiss }`. Set `dismiss: true` to close the toast after the click. |
| `actionPlacement` | `"inline" \| "below"` | `"inline"` | `inline` puts the action right next to the title, `below` underneath it. |
| `actionVisibility` | `"always" \| "hover"` | `"always"` | `hover` only shows the action while the toast is hovered or focused. |
| `dismissible` | `boolean` | `true` | Allows swipe, the close button and Escape. |
| `autoExpand` | `boolean \| { delay?, hold? }` | `true` | Opens the body by itself when there is a description. `delay` is the wait before opening (default `220`); `hold` how long it stays open (default: until 1.5 s before it is dismissed, or for good when it has no duration). |
| `keepExpanded` | `boolean` | `false` | Once the body has opened, by itself or on hover or focus, it stays open instead of collapsing when `hold` runs out or the pointer or focus leaves. |
| `fill` | `string` | theme | Background colour of the shape. |
| `radius` | `number` | `--seintje-radius`, else `18` | Corner radius in pixels. |
| `important` | `boolean` | `true` for errors | Announce through the assertive live region. |
| `className` | `string` | — | Class on the toast element. |
| `classes` | `{ toast?, title?, description?, icon?, action? }` | — | Classes on the toast's parts. `toast` is added next to `className`. |
| `onDismiss` | `(id) => void` | — | Called when the toast starts to leave. |

## Content

In the core, `Content` is a string, a DOM `Node`, or a renderer
`(slot: HTMLElement) => void | (() => void)`. The Vue package also accepts VNodes and
components; the Svelte package accepts snippets and `{ component, props }`.
