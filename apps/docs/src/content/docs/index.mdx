<CardGrid>
  <Card title="Works anywhere" icon="seti:javascript">
    The core is plain TypeScript and DOM. Use it from a bundler, or straight from a CDN in a
    `<script type="module">` tag.
  </Card>
  <Card title="Vue and Svelte" icon="puzzle">
    `@seintje/vue` and `@seintje/svelte` mount the same core and let you put VNodes, components
    and snippets inside toasts.
  </Card>
  <Card title="Real springs" icon="rocket">
    Every movement runs through the framework-agnostic `animate()` from
    [motion](https://motion.dev), so interrupted animations keep their momentum.
  </Card>
  <Card title="Accessible" icon="approve-check">
    Live-region announcements, keyboard focus with <kbd>Alt</kbd>+<kbd>T</kbd>, Escape to
    dismiss, timers that pause on focus, and `prefers-reduced-motion` support.
  </Card>
</CardGrid>
